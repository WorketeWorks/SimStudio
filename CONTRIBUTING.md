# Contributing to Sim Studio

Thanks for your interest in improving the project. For larger changes, please
open an issue first so we can agree on the approach.

## Quick start

1. Fork the repository and create a descriptive branch from the main branch.
2. Install dependencies with `npm install`.
3. Run the project with `npm run dev`.
4. Keep changes focused on one problem.
5. Before opening a pull request, run `npm run build` and `npm run lint`.

## Pull requests

- Explain what changed and why.
- Include steps to reproduce or test the change.
- Add screenshots or a video if the change affects the 3D interface.
- Update the documentation when visible behavior changes.
- Do not include secrets, credentials, or unnecessary generated files.

## Code and third-party data

Follow the existing style and dependencies. LDraw models and files retain
their own notices, authors, and license terms; do not replace them with this
repository's MIT license.

If you find a security issue, do not publish it in an issue. Contact the
maintainers privately.
