# Security Policy

## Supported Versions

Sim Studio is currently under active development. Security updates apply only
to the latest version on the `main` branch.

| Version | Supported |
| ------- | --------- |
| `main` / latest release | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

Please report security vulnerabilities privately through [GitHub Security
Advisories](https://github.com/WorketeWorks/SimStudio-LEGO-Technic-Physics-Simulator/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- The affected version, commit, or component.
- Any suggested mitigation, if available.

We will acknowledge valid reports as soon as practical, investigate them, and
coordinate disclosure after a fix or mitigation is available. The response
and remediation timeline may vary depending on severity and complexity.
